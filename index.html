FinBrasil Analytics

Pipeline de dados completo para indicadores macroeconômicos brasileiros. Coleta dados em tempo real das APIs do Banco Central e IBGE, processa em camadas (Medallion Architecture) e entrega um dashboard interativo com KPIs, médias móveis e análise de séries temporais.

  • SELIC, CDI, IPCA, câmbio USD/BRL, PIB — Banco Central do Brasil
  • Desemprego e rendimento médio — PNAD Contínua / IBGE
  • Pipeline agendado diariamente às 06h via Apache Airflow
  • Testes de qualidade de dados com dbt
  • Armazenamento em Parquet + consultas SQL via DuckDB
  • Infraestrutura completa containerizada com Docker Compose

Flow Carreiras

Plataforma para impulsionar a carreira de novos artistas de Recife, conectando-os a mentores e oportunidades de mercado. Aplicação full-stack em produção com uma camada analítica robusta para entender engajamento, perfis profissionais e otimizar a descoberta de talentos.

  • Backend Java 17 / Spring Boot com autenticação JWT + BCrypt e JPA/Hibernate
  • Frontend React + Vite + Tailwind, PWA com Workbox, servido via Nginx
  • Dashboards de métricas (pessoais e globais) integrados à interface web
  • Módulo de Data Science: EDA, regressão de engajamento e classificação da Fila de Descoberta
  • Base analítica com 400 perfis simulados, migrações via Flyway
  • Stack containerizada com Docker Compose, deploy em Vercel + Render

OdontoHub

  • Modelagem com DDD e Context Mapper (10 bounded contexts)
  • 7 padrões: Repository, Adapter, Data Mapper, Observer, Factory, DI, Facade
  • Domain Events integrando contextos (Estoque/Pagamento → Fluxo de Caixa)
  • Cenários BDD em Gherkin com Cucumber + JUnit
  • Minha contribuição: F4 — Fluxo de Caixa & F5 — Controle de Estoque
